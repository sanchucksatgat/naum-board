# 나눔보드 사용 안내 (선생님용)

설치가 끝났다면 내 나눔보드 주소(`https://nanumboard.○○.workers.dev`)에서 **Google로 로그인**하고 시작해요.
화면 위쪽 메뉴는 **보드 · 반·명단 · 포트폴리오** 세 가지예요.

---

## 1. 만들기

### 반·명단 (명단 입장 보드를 쓸 때만)

1. **반·명단** → **+ 새 반 만들기** → 반 이름을 적어요.
2. **학생 명단 붙여넣기** 칸에 엑셀·구글 시트에서 표를 복사해 붙여 넣어요. 한 줄에 한 명, `학번 · 이름` 은 꼭, `PIN · 모둠 · 닉네임` 은 없어도 돼요.
   첫 줄이 `학번, 이름, PIN, 모둠` 같은 제목이면 그 순서대로 읽어요. PIN 을 비우면 4자리를 자동으로 만들어요. CSV 파일도 **CSV 파일 고르기**로 넣을 수 있어요.
3. 아래 미리보기에서 빨간 줄이 없으면 **반 만들고 N명 넣기**.
4. 반 화면에서 **PIN 쪽지 인쇄**로 학생마다 학번·초기 PIN 쪽지를 뽑아 나눠 줘요.
   - 학생은 처음 들어올 때 쪽지의 초기 PIN 을 넣고 **나만의 PIN** 을 새로 정해요. 그 뒤로는 선생님도 PIN 을 볼 수 없어요.
   - 잊었다면 학생 줄의 **PIN 초기화** → 새 초기 PIN 을 알려 주세요.

### 보드

**보드** → **+ 새 보드 만들기**

| 항목 | 고르는 것 |
|---|---|
| 보드 유형 | **여러 장 누적**(관찰 기록·활동 모음) / **학생당 1카드**(한 질문에 대한 생각 나누기) |
| 열 구성 | **개인별**(학생마다 칸) / **모둠별**(명단의 모둠마다 칸) / **주제별**(선생님이 정한 주제마다 칸, **주제 이름**에 한 줄에 하나) |
| 학생 입장 방식 | **명단 입장**(학번 + PIN, 누가 썼는지 확실하고 안 쓴 학생을 볼 수 있음 → **반 고르기**) / **자유 입장**(닉네임만, 연수·공개 수업용) |
| 옵션 | **승인 후 게시**, **익명 모드**, **좋아요 허용**, **댓글 허용** |

**보드 만들기**를 누르면 바로 입장 코드와 QR 이 나와요.

## 2. 공유

- 보드 카드의 **공유·QR** (또는 보드 관리 화면): 입장 코드 6글자, QR, 학생 입장 주소(**복사**).
- **프로젝터로 크게 보기**: 교실 화면에 QR 과 코드를 크게 띄워요.
- 학생은 휴대폰 카메라로 QR 을 찍거나, 주소창에 주소를 치고 코드를 넣어요. 앱 설치·회원 가입은 없어요.

## 3. 수업 중

**보드 열기**로 학생과 같은 화면을 열면 위쪽에 선생님 도구가 보여요.

- **🔒 잠그기 / 🔓 잠금 풀기**: 잠그면 학생은 읽기만 해요(글·댓글·좋아요 불가).
- **⚙️ 빠른 설정**: 익명 모드, 승인 후 게시, 댓글·좋아요 켜고 끄기.
- **⏳ 승인 대기 N**: 승인 후 게시 보드에서 기다리는 카드로 이동. 카드 아래 **✅ 승인**을 누르면 모두에게 보여요. 승인 전 카드는 쓴 학생과 선생님만 봐요.
- 카드 아래 **🙈 숨기기 / 👁️ 다시 보이기**, **📝 피드백**(그 학생과 선생님만 보여요).
- **📝 안 쓴 학생 N** (명단 입장): 아직 카드를 안 쓴 학생과 접속 여부.
- **📢 공지 쓰기**: 보드 맨 위 공지. 고치기·지우기는 공지 옆 단추.
- 주제별 보드: **＋ 칸 추가**, 칸 이름 옆 **⋯** → **✏️ 이름 바꾸기 / ← 앞으로 / 뒤로 → / 🗑️ 지우기** (카드가 있는 칸은 못 지워요).
- 학생 칸의 **+ 대신 쓰기**: 그 학생 이름으로 카드를 대신 써 줘요.
- 남의 댓글이 문제라면 댓글을 열어 **댓글 지우기**.
- **📺 프로젝터**: 교사 도구 없이 큰 글씨 화면. **👀 학생 화면**: 학생이 보는 모습을 새 창으로.
- 오른쪽 위 백업 표시: **☁️ 백업됨**(드라이브에 저장됨), **⚠️ 백업 실패**(잠시 뒤 자동으로 다시 시도), **⚠️ 백업 실패 · Drive API 켜기**(누르면 해결 방법), **⚠️ 드라이브 연결 끊김**(선생님 화면에서 다시 로그인).

학생이 PIN 을 5번 틀리면 5분 동안 잠겨요. 기다리기 어렵다면 **반·명단** → 그 반 → 학생 줄의 **잠금 풀기**.

## 4. 수업 후

보드 관리 화면(보드 카드의 **관리**)에서:

- **구글 시트로 내보내기**: 모든 글을 한 장의 시트로 만들어 드라이브 폴더에 저장하고 새 창으로 열어요 (학번·실명·좋아요·댓글·피드백 포함).
- **드라이브 폴더 열기**: 이 보드의 사진·파일·`게시글 백업.json`·내보낸 시트가 있는 폴더.
- **보관하기**: 수업이 끝난 보드를 정리해요. 학생은 들어올 수 없고 선생님은 읽기만, 언제든 **보관 풀기**.
- **지우기…**: 보드 이름을 그대로 쳐야 지워져요. 되돌릴 수 없고, 드라이브의 사진·백업 파일은 남아요.
- **포트폴리오**(위 메뉴 또는 학생 줄): 한 학생이 그 반 보드들에 쓴 카드를 모아 보고 인쇄해요.
- 대시보드의 **최근 올라온 글**: 모든 보드의 최근 글(최대 30초 늦게 보여요).

## 자주 묻는 것

- **학생 이름이 다른 학생에게 보이나요?** 익명 모드를 켜면 학생 화면에는 친구 이름 대신 "익명"이 보여요. 선생님은 언제나 실명을 봐요.
- **학생이 휴대폰을 바꿨어요.** 명단 입장은 학번 + 나만의 PIN 으로 어디서든 들어와요. 자유 입장은 같은 기기여야 내 카드를 고칠 수 있어요.
- **설치가 잘 됐는지 다시 보고 싶어요.** `내 주소/setup` 의 마지막 단계 **설치 점검**.
